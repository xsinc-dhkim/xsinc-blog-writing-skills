# 에브리팁 작성 기준

`에브리팁`의 목적과 실제 기존 문체는 공식 블로그 게시물을 읽어 글별로 확인한다. 페이지를 읽지 못한 상태에서 고정된 톤을 추정하지 않는다.

## 기본 전개

글의 목적에 맞춰 다음 흐름을 출발점으로 사용한다.

1. 독자가 궁금해할 문제나 상황
2. 먼저 알아야 할 짧은 결론
3. 이해 또는 실행에 필요한 핵심 내용
4. 조건, 예외와 주의사항
5. 다음 행동 또는 확인 경로

## 작성 원칙

- 유용한 정보를 먼저 제공하고 서비스 홍보를 억지로 끼워 넣지 않는다.
- 독자의 이용 상황, 비용 절감, 안전성이나 성공 결과를 근거 없이 단정하지 않는다.
- 일반 정보와 에브리뷰 서비스의 기능·정책을 구분한다.
- 서비스 기능·정책을 설명할 때는 사용자가 제공한 현행 근거에 연결한다.
- 기존 게시물과 제목·문장을 길게 복제하지 않는다.
