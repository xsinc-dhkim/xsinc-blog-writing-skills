# 원고 검수 기준

## 사실과 근거

- 서비스 기능, 가격, 적용 범위와 시점이 현행 원천에 연결되는가.
- 기존 게시물의 과거 사실을 현재 상태로 복사하지 않았는가.
- 일반 정보와 에브리뷰 서비스 설명을 구분했는가.
- OTT와 AI의 향후 계획을 현재 운영 카테고리로 표현하지 않았는가.
- 미확인 효익과 보장 표현을 제거하거나 `확인 필요`로 표시했는가.

## 독자와 전개

- 독자가 글을 읽을 이유와 먼저 알아야 할 결론이 드러나는가.
- 승인된 브리프의 목적, 핵심 메시지와 구조를 따르는가.
- 블로그 맥락 스캔에서 확인한 최근 주제와 불필요하게 중복되거나 충돌하지 않는가.
- 공식 블로그를 읽었다면 참고한 문체와 구조가 과도한 복제 없이 반영됐는가.

## 형식과 권한

- 제목이 실제 내용을 정확히 보여주는가.
- 키워드가 지정됐다면 억지스럽게 반복하지 않았는가.
- 임시 표기와 자리표시자가 남아 있지 않은가.
- CTA가 브리프의 목적과 확인된 범위에 맞는가.
- 게시하거나 최종 승인했다고 표현하지 않았는가.

## 보고 형식

```markdown
## 검수 결과

- 통과:
- 수정 제안:
- 확인 필요:
- Skill 개선 후보: 없음 또는 제안 1건
```
