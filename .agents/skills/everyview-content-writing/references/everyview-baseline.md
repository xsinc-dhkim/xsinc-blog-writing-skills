# 에브리뷰 공식 채널과 현재 범위

확인 기준일: 2026-09-18

## 공식 주소

- 에브리뷰 공식 네이버 블로그: https://blog.naver.com/everyview-
- 확인용 에브리팁 게시물: https://blog.naver.com/everyview-/224414582869

## 운영 상태

- 현재 운영한다고 전달받은 카테고리는 `에브리팁`이다.
- OTT와 AI 카테고리는 향후 추가 계획이다. 계획을 현재 운영 상태로 표현하지 않는다.
- 위 주소는 참고 위치를 알려준다. Skill이 기존 게시물 전체를 내장하거나 자동으로 최신 상태를 보장한다는 뜻이 아니다.

## 근거 사용

- 공식 블로그 게시물: 제목, 문체, 전개와 CTA 참고.
- 사용자가 제공한 최신 기능·정책 자료: 해당 글의 서비스 사실 근거.
- 게시물 작성 당시의 기능·가격·조건은 별도 확인 없이 현재 사실로 재사용하지 않는다.

## 공식 블로그 맥락 스캔

- 새 글 작업을 시작할 때 최근 흐름을 파악할 수 있는 최신 에브리팁 게시물 3~5건을 읽고, 주제가 정해졌다면 유사 게시물도 최대 3건 확인한다. 숫자는 기본 범위이며 충분한 맥락을 얻으면 조정할 수 있다.
- `최근에 다룬 내용 / 반복되는 톤앤매너와 구성 / 새 글과 겹치는 주제 / 참고할 설명과 링크 / 새 자료와 충돌하거나 오래됐을 가능성이 있는 내용`을 구분해 정리한다.
- 접근하지 못하면 읽었다고 말하지 않고 사용자에게 최근 게시물 링크, 본문 또는 화면을 요청한다.
- 스캔 결과는 문체·구조·주제 맥락이다. 게시 당시의 기능·가격·정책은 사용자가 제공한 현행 자료와 일치할 때만 현재 사실로 사용한다.
