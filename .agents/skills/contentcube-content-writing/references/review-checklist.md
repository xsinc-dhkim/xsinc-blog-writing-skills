# 원고 검수 기준

## 사실과 근거

- 기능·수치·적용 범위·시점이 글별 원천에 연결되는가.
- 화면에 보이는 항목과 실제 사용 가능 상태를 구분했는가.
- 미확인 효익과 보장 표현을 제거하거나 `확인 필요`로 표시했는가.
- 첨부 이미지의 내용과 설명이 일치하는가.

## 독자와 전개

- 처음 접하는 독자가 서비스·용어·글을 읽을 이유를 이해할 수 있는가.
- 독자의 상황을 임의로 단정하지 않았는가.
- 승인된 브리프의 목적·핵심 메시지·구조를 따르는가.
- 기능 나열에 그치지 않고 확인된 운영상 의미가 드러나는가.

## 문체와 형식

- 친근하고 전문적인 해요체가 일관되는가.
- 제목 후보가 글의 실제 내용을 정확히 보여주는가.
- 키워드가 지정됐다면 억지스럽게 반복하지 않았는가.
- 임시 표기와 자리표시자가 남아 있지 않은가.
- CTA가 브리프의 목적·권한 범위와 맞는가.

## 보고 형식

원고 뒤에 아래 형식으로 짧게 보고한다.

```markdown
## 검수 결과

- 통과:
- 수정 제안:
- 확인 필요:
- Skill 개선 후보: 없음 또는 제안 1건
```
