# 콘텐츠큐브 초기 작성 기준

이 문서는 2026-09-18 파일럿을 위한 초기 기준이다. 상품 기능·가격·정책의 현행 정본이 아니며, 글별 원천보다 우선하지 않는다.

## 독자와 목적

- 기본 독자는 콘텐츠큐브를 처음 접할 수 있는 숙박업 운영자다. 글별 브리프에서 다른 독자를 정하면 그 범위를 따른다.
- 정보 전달을 우선하고, 독자가 기능의 역할·사용 조건·운영상 의미를 이해하도록 돕는다.
- 확인되지 않은 매출 증가, 비용 절감, CS 감소나 보편적 효익을 약속하지 않는다.

## 문체

- 친근하고 전문적인 해요체를 사용한다.
- 독자의 상황을 임의로 단정하지 않는다.
- 짧고 구체적인 문장과 한 문단 한 핵심을 기본으로 한다.
- 기능을 처음 접하는 독자가 맥락 없이도 이해할 수 있게 서비스·용어를 먼저 설명한다.

## 근거 역할

- 공개 콘텐츠큐브 블로그: 문체, 제목, 전개와 CTA 참고.
- 사용자가 제공하거나 지정한 기능 문서·화면: 해당 글의 현재 사실 근거.
- 지정한 Notion·시트: 전달받은 페이지·범위와 기준 시점 안에서만 사용.
- 키워드 자료: 존재와 현재성을 확인한 경우에만 적용. 검색 순위나 성과를 보장하지 않는다.

## 공통 경계

- 근거가 없는 기능, 적용 범위, 수치, 지원 결제수단을 확대하지 않는다.
- 화면에서 선택지가 보인다는 사실과 실제 사용 가능하다는 사실을 구분한다.
- 과거 글의 표현을 현재 상품 사실로 복사하지 않는다.
- 외부 게시를 위한 최종 승인과 실제 발행은 Skill 범위 밖이다.
