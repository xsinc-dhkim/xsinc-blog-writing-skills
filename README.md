# xsinc-blog-writing-skills

엑세스 브랜드의 네이버 블로그 원고를 작성하고 검수하는 Agent Skills 모음입니다.

## 포함된 Skill

- `contentcube-content-writing`: 콘텐츠큐브 기능 소개, 기능 업데이트, 이용 방법, FAQ, 서비스 소식
- `everyview-content-writing`: 에브리뷰 공식 블로그의 에브리팁 콘텐츠

## 설치

ChatGPT 데스크톱이나 Codex에서 이 저장소의 두 Skill을 설치해 달라고 요청하세요.

설치 후 새 대화에서 다음과 같이 시작할 수 있습니다.

> 콘텐츠큐브 기능 업데이트 블로그 글을 만들자.

또는:

> 에브리팁 블로그 글을 만들자.

Skill은 브리프 승인을 받은 뒤 초안을 작성하며, 외부 게시나 예약 발행은 수행하지 않습니다.
