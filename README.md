# cc-writing-skill

콘텐츠큐브 네이버 블로그의 기능 소개, 기능 업데이트, 이용 방법, FAQ, 서비스 소식 원고를 작성하고 검수하는 Agent Skill입니다.

## 설치

ChatGPT 데스크톱이나 Codex에서 이 저장소의 `contentcube-content-writing` Skill을 설치해 달라고 요청하세요.

설치 후 새 대화에서 다음과 같이 시작할 수 있습니다.

> 콘텐츠큐브 기능 업데이트 블로그 글을 만들자.

Skill은 브리프 승인을 받은 뒤 초안을 작성하며, 외부 게시나 예약 발행은 수행하지 않습니다.
